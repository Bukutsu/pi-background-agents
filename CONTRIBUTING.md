# Contributing

## Setup

```bash
git clone https://github.com/Bukutsu/pi-background-agents.git
cd pi-background-agents
bun install
```

## Type Check

```bash
bun run check
```

## Submitting a Pull Request

1. Fork the repository and create a branch from `master`.
2. Make your changes and run `bun run check` to confirm no type errors.
3. Open a pull request with a clear description of what changed and why.

Please keep pull requests focused. One change per PR makes review easier.
